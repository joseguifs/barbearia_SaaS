# 📚 Sobre o Projeto

O **BarberTime** é um projeto desenvolvido para a disciplina de **Engenharia de Software 2026.1** da **Universidade Federal do Tocantins (UFT)**, no curso de **Ciência da Computação**, ministrada pelo professor **Dr. Edeilson Milhomem da Silva**.

A proposta do sistema é desenvolver uma plataforma web no modelo **SaaS (Software as a Service)** voltada para o gerenciamento de agendamentos em barbearias.

O projeto surge como uma solução moderna para digitalizar e automatizar processos que normalmente são realizados manualmente, proporcionando mais organização, eficiência operacional e melhor experiência para clientes e administradores.

Além do contexto acadêmico, o BarberTime possui potencial de evolução para uma solução comercial escalável.

---

# 🎯 Objetivo

Desenvolver uma plataforma capaz de:

## 👤 Clientes
- Realizar agendamentos de forma prática
- Consultar horários disponíveis
- Acompanhar histórico de atendimentos

## 💈 Barbeiros
- Organizar agendas de atendimento
- Visualizar compromissos diários
- Controlar atendimentos realizados

## 🛠️ Administradores
- Gerenciar barbeiros
- Cadastrar serviços
- Definir preços e duração dos serviços
- Controlar agendamentos do sistema

---

# 🚀 Benefícios da Plataforma

O BarberTime busca substituir processos manuais por uma solução digital eficiente, oferecendo:

- 📅 Organização inteligente de horários
- ⏱️ Redução de conflitos de agenda
- 💈 Melhor gerenciamento operacional
- 👥 Melhor experiência para clientes
- 📊 Maior controle administrativo
- 🌐 Facilidade de acesso através da web
